# 上证综指盘后日均线

盘后主报告计算上证综指（000001.SH）5、10、20、60 日简单移动平均。每个周期包含目标日，以本地 SSE 日历向前取足对应开放日。程序逐自然日检查日历，只在本周期日历连续、每个应到交易日都有有效收盘时发布均线。均线显示两位小数，收盘在线上或线下按未舍入均值判断。休市、缺日、错票和未收盘行情均保留缺口。

当日盘后优先采用身份、事实日核验通过的指数收盘；历史收盘从 `market_timing_signal` 的上证 Tushare 指数记录和复盘证据中的 Tushare 指数日线、通达信上海市场指数日线读取。程序按上海时间核验可见性，过滤抓取当天尚未收盘的日线。实时盘后仍缺数据时只查询一次覆盖缺口的指数区间。历史回放读取目标日原盘后信封的生成时间，另取的当日行情与原始证据冲突时标为待核。同一交易日的收盘只进入一个样本。

证据位于 `raw_data.moving_averages.shanghai.daily_ma_evidence`，包含研究截止时间、窗口起止、有效与应到天数、已知缺失日期及各日来源。现有 `ma5` 至 `ma60` 和对应的 `above_ma*` 字段只在周期完整时出现。穿越信号按同一事实集分别重算当日和严格上一开放日，两窗都完整才比较。旧版只有均线值的历史报告不能充当相邻基准。四指数和平均股价既有 5 周均线继续走周线流程。

市场概览接口 `/api/market/{date}` 与复盘预填当日、前日行情共用只读视图。旧版已发布的日均线和穿越存入返回值内的 `moving_averages.shanghai.archived_unverified` 供追溯。视图在当前请求的数据库及与该库对应的复盘证据目录内核验窗口，只有通过验证的值及穿越进入主字段。无法定位同源库或缺证据时显示覆盖缺口。原始盘后信封保留历史记录。

原盘后信封的事实日或生成时间无法核验时，历史只读视图把截止时刻收紧到当天上海 15:00，并说明原因。收盘之后取得且无法证明原报告可见的补采数值不能填补当天缺口。
