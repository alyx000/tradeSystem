# 前夜重点题材的快讯与首次可见时间

按上海时间和 SSE 开放日，读取严格上一开放日的手写复盘及其开盘前已录入的有效版本。选题沿用显式跟踪指令或题材分组标题，报告保存原句、版本哈希及录入时刻。逐条匹配金十标题和正文里的题材原词，英文缩写检查词边界。复合词、股票简称与题材同义词可能漏项；短中文词也可能命中其他词组。命中是检索证据，是否构成产业催化、何时影响市场需结合原文和行情判断。

## 运行与文件

既有盘中异动任务按上海时钟每 10 分钟产生一个时槽，09:32–11:22、13:02–14:52 共 24 槽。工作日盘后宏观快讯成功归档后，可以从当日留存的同一金十流核验其余报道。文件为 `data/reports/theme-catalysts/YYYY-MM-DD.json`。

```sh
python3 scripts/tools/theme_catalysts.py --scheduled-at 2026-11-30T09:32:00+08:00 --input-by launchd
python3 scripts/tools/theme_catalysts.py --archive --date 2026-11-27 --input-by USER
```

第一条命令需要在指定日、相应时槽的前三分钟内运行。收盘后回看使用第二条命令，先校验宏观快讯原文件 SHA-256、窗口、提交回执、单条 ID 唯一性及媒体时间。已留存盘中证据按条合并。报告按金十 ID 归并，原始条目变动用不同 SHA-256 留存版本。同一版本重复采到时保留最早实收时间；每条的来源回执可查，失败的时槽保留缺口。重复盘后导入复用同一回执。

| 报告字段 | 可以说明什么 |
|---|---|
| `media_published_at` | 金十 `time`，按上海时间保存。 |
| `first_seen_at` | 本系统盘中取得该条原文版本的最早实收时刻，精确至返回该页的时间。历史只有晚间文件时为空。 |
| `known_by_at` | 最迟此时本机已有该条证据。取能校验的同版实时返回及原档生成时刻中最早值。 |
| `credited_source`、`credited_url` | 金十给出的署名和链接，保留公众号和媒体转载链接。 |
| `original_org`、`original_url` | 金十署名与已登记的机构自有站点同时吻合。只有媒体署名或公共发表平台链接时留空。 |
| `original_published_at`、`original_time_evidence` | 机构原文 HTML 明确的发布时间元标签以及取证时间、URL 与响应内容哈希。只有日期、只有修改时间、标记冲突、时间晚于转载或页面不可达时，原发时刻留空。 |
| `kind`、`matched_terms` | 标记明确行情播报、金十汇总、机构链接或一般报道。保留命中词与原文便于逐条判断。 |
| `receipts`、`coverage` | 记录每次窗口、页数、来源状态、丢弃数和实际返回的槽位。盘后快讯回执与实时覆盖分别统计。 |

常规槽查询前 15 分钟，上午第一槽从当日零时起尝试，下午第一槽从 11:20 起尝试，以覆盖午休发布。常规最多 4 页，两个首槽最多 8 页，翻页软预算 12 秒，每次连接和读取分别限制 2/3 秒。高密度新闻、时间预算或接口失败会保留截断或失败状态。每个盘中槽最多再查一篇命中报道的机构原文。盘后导入只读取本机文件。金十对结构异常的原始条目会计入丢弃数，`complete` 表示分页覆盖到了请求起点。
