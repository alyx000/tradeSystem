# 非ST跌停触价与收盘修复

20:00 盘后使用现有五项来源，逐股保存当日跌停价、最低价、最高价和收盘价。当日成交最低价等于真实下限即记为触价。对于这些股票，分别列出收盘仍等于下限及收盘已高于下限的数量和名单。数量单位是股票只数，不是开板或回封次数。

`raw_data.limit_down_touch` 与原盘后信封双写。核验同日未复权日线、涨跌停价、ST 名单、按上市及退市日期还原的沪深北 A 股名单和全天停牌。剔除 B 股、ST、退市标记、全天停牌和当日不设涨跌幅限制的股票。缺行情必须有全天停牌证明，有成交和全天停牌冲突、低高收互相矛盾、交易日或来源缺失时单独降级。有效收盘跌停名单与现有跌停模块逐股对照。保留按证券排列的日线证据用于复算、来源范围和 SHA-256。

盘后摘要及正式复盘 HTML 的③情绪区都显示触价、收盘仍跌停、收盘离开三项。复盘按所选事实日读取，优先同日盘后新块；旧日可使用该日独立回验，旧日无来源时显示待核。独立回验仅消费已有五份日期来源文件，逐个核对 SHA-256 和取数回执，不回写历史盘后归档，不推送。

从项目根目录复算并保存日档：

```sh
python3 scripts/tools/limit_down_touch.py --date 2026-11-27 --input-by USER --save
```

结果为 `data/reports/limit-down-touch/YYYY-MM-DD.json` 和同名 Markdown。JSON 保存逐股证据和原始文件来源，Markdown 列出全部触价股。日内首次打开、再次触价、持续时间或盘口挂单量需要另外的盘中记录。
