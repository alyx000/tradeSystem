# 盘中半小时扫描：内容与本地预览

2026-11-16 起，报告采用结论前置、上一期对照、板块榜单持续性三个展示改进。行情采集、计算阈值、原榜单排序、调度及发送去重规则不变。

- 结论先说明区间扩散；当个股中位数与上涨占比满足原强弱阈值时，用上证半小时涨幅 ±0.05% 作辅助对照。该阈值仅为阅读摘要规则，不是交易信号。板块摘要仅复述正向/负向区间排名。
- 只读同日严格上一槽位 Markdown 的原始事实段。完整性、日期、区间、数量、占比和榜单结构校验失败时，停止跨期比较。10:00 和 13:30 没有上一期半小时报告，不跨开盘或午休拼接。
- 对照显示区间上涨占比、中位数、区间跌幅≥1%数量、当日跌幅≥5%数量。比例变化用百分点；各列分别标注区间及当日口径。归档汇总值没有逐股固定样本证明，所以不称同一批股票恶化，不把数量差称为新增名单。
- 板块仅比较相邻两期同方向前五名单，标记连续两期上榜、本期新上榜和退出前五。不表示连续涨跌、板块带动关系、历史首次上榜；退出不等于转强或转弱。不宣称连续时长恰好只有两期。
- 15:00档保持实时快照属性，不冒充最终收盘核验。
- 旧归档显示精度不足时保护原判断：中位数显示为±0.15%、上涨占比显示为40%/60%、上证区间涨幅显示为±0.05%时，预览沿用归档判断，不拿四舍五入后的数值跨阈值重判；原判断缺失或重复则明确不重判。行业金额缺失不影响独立的榜单/市场对照。
