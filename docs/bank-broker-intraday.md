# 银行与证券盘中强弱

沿用盘中异动的 24 个十分钟采样时槽。银行取申万二级的国有大型银行Ⅱ、股份制银行Ⅱ、城商行Ⅱ及农商行Ⅱ，证券取证券Ⅱ。范围为该交易日盘中冻结的可观察 A 股，沿用原采样对 ST、退市与 B 股的排除。各时槽保留报价来源、实际采样时间、逐股源报价时刻、最新价及昨收、两组的应有和有效家数、上涨家数与逐股涨幅中位数。差值为证券中位数减银行中位数，单位为百分点。各股权重相同；本项观察样本内部强弱，无法辨认交易者或资金流向。

工作日 20:00 通过现有盘后任务读取同日已签收批次。手工复核可在仓库根目录运行：

```shell
/usr/bin/python3 scripts/tools/bank_broker_intraday.py --date 2026-11-27 --input-by USER --save
```

省略 `--save` 只读重算。逐股依据位于 `data/reports/bank-broker-intraday/YYYY-MM-DD.json`；同目录同名 HTML 可直接查看该日全部时槽。完整或跳过退出 0；部分覆盖、来源失败或重跑保留更完整旧日档时退出 2。重跑加锁并原子落盘。较差回放保留旧日档并另存重试回执。每次保存后由已核验的日档生成 HTML。正式复盘②与板块增量归因一同装配，取报告事实日的独立日档并校验哈希，展示最近一批和可展开的全天明细，旧报告不会重写。

每一批核验报告哈希、原行情、范围和行业来源，核对冻结名单与当时的统一成员身份。逐股报价须属于同日连续交易时段，报价不得晚于采样时刻，报价年龄最多 90 秒。股价和参考昨收复算出的涨幅须与源涨幅一致（兼容保留 2 位小数的报价）；中位数使用逐股保留 4 位小数的涨幅。缺股票只统计实际有效样本；无行情时上涨家数及中位数留空。缺子行业时分母待核。两组覆盖均完整才给出中位涨幅差。重复或失败批次所在时槽留空，同日冻结成分冲突时暂停比较。无计划时间的老归档按实际采样时间归入现有时槽，日档的 `scheduled_at` 留空。
