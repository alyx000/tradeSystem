# 盘中异动采样与钉钉提醒

本机 LaunchAgent 在 SSE 开放日每 10 分钟采样一次。行情和研究候选保存在本地。个股或行业出现符合下述条件的新变化时，当批合发一条钉钉短报。手写复盘的个股和宽基关键位只进入本地摘要。

## 采样与回执

上海时间上午 09:32—11:22、下午 13:02—14:52，每半场 12 个计划时点。定时入口在计划分钟及随后两分钟内接受启动，通过交易日历核验后才请求行情。每槽只采一批。切换半场、切换周期、行情失败或采样断档后，下一批重新建立基线。休眠错过的时点不补采。部署说明见[本机盘中采样](../deploy/launchd/README.md#盘中异动采样)。

以下命令用于在仓库根目录核对单批计算或从指定日期的现有归档重建摘要。手动单批默认周期为 5 分钟，`--interval-minutes 10` 选择正式采样间隔。前台的 `--watch --samples N` 支持 1—48 轮，在午休或收盘时停止。

```bash
python3 scripts/tools/intraday_events.py --interval-minutes 10 --dry-run --input-by USER
python3 scripts/tools/intraday_events.py --summarize-date YYYY-MM-DD --input-by USER
```

批次保存在 `data/reports/intraday-events/YYYY-MM-DD/` 下的独立子目录。先写 `report.md`、`report.json` 和绑定报告 SHA-256 的 `receipt.json`，再更新 `latest.json`。定时采样回执保存计划、实际开始、采到行情的三个时刻。并发运行受采样锁保护，最近批次损坏时报告缺口。核对采样间隔应使用两批的 `captured_at`。

钉钉的投递结果另存 `delivery.json`。核对批次、事实日、请求者和报告哈希后，`accepted` 表示钉钉已接收，`quiet` 表示没有达标新提醒，`no_comparison` 表示本批无法比较。发送中、接收未确认、过期和未配置均保留各自状态。历史回放仅使用本地行情及回执。

## 手写复盘来源

固定对象取严格上一 SSE 开放日的手写复盘归档。系统先校验原文、整理稿和修订链，选取本交易日 09:30 开盘前的有效版本。缺档或链损坏时标记缺源，开盘后的修订不倒灌。原文点名与证券身份须精确匹配。对仅凭配图整理的复盘，固定对象表和次日条件表的主对象须共同指向同一名称及代码。单纯对照提及和无法消除歧义的身份保留待核。

手写复盘通过独立 CLI 归档。新稿记录原文、整理稿及请求者。修订以当前整理稿哈希校验版本，追加新稿并保留旧稿。

```bash
python3 scripts/tools/handwritten_review.py import --date YYYY-MM-DD --source-file SOURCE.txt --supplement-file SUPPLEMENT.md --input-by USER
python3 scripts/tools/handwritten_review.py amend --date YYYY-MM-DD --supplement-file REVISED.md --expected-sha256 CURRENT_SHA256 --reason '修订原因' --input-by USER
python3 scripts/tools/handwritten_review.py build --input-by USER
```

## 钉钉选择与短报文案

- **手写个股锚点。** 相邻窗口区间涨跌幅绝对值达到 2% 才有资格提醒。连续两窗同方向达标时去重。同一股票距上次可能送达的提醒采样时间不足 30 分钟时，区间涨跌幅绝对值须达到 3%。今日已入选过同一方向的提醒还须突破此前同日采样高点或低点，或相对上次同方向入选时的位置跨过昨收。午休前的日内高低点及提醒记录仍参与判断。
- **入选说明。** 区间上涨后仍低于昨收，或区间下跌后仍高于昨收时，短报给出相对昨收的方向和幅度。重报保留本次入选原因。能核验当日最近一条同股同向已接收回执、实发正文和当批报价时，再列该采样时刻及现价相对当时的变化。发送中或接收未确认的回执参与防重，已接收的报价单独核对。历史防重依据损坏时暂停当批锚点提醒，行业计算可独立继续。
- **行业。** 申万二级行业至少有 8 个成员，区间涨跌幅中位数绝对值达到 0.6%，且同方向成员占比达到 70%。达到上述条件后，新出现与市场中位数反向且相差至少 1 个百分点的行业可提醒。锚点所属行业也可在连续两窗同向达标的第二窗提醒，此时相对市场的同向领先或落后幅度须达到 0.6 个百分点，较前窗扩大至少 0.3 个百分点。每批短报最多点名三个行业，完整候选留在本地。

短报标题使用两批的实际采样时刻，逐股列区间变化及相对昨收的表现。无新变化的批次静默。上述门槛用于记录观察事件。

## 固定样本与研究候选

每日冻结证券范围、申万二级映射、事前人工核心、昨日强势样本和来源哈希。证券范围剔除 ST、退市和沪深 B 股后须至少 4,000 只。采集完成时，新鲜有效的当日报价覆盖须达到 95%，报价距采集时刻不超过 90 秒。原始行情及其哈希随批保存。行业映射须覆盖整个有效范围，分组事件须覆盖全部固定成员。样本不足时保留覆盖率、缺失代码与可计算指标。

同日、同半场、固定上下文且相同采样周期的相邻快照方可比较。5 分钟模式接受 4—7 分钟有效窗口，10 分钟模式接受 7—13 分钟。除上述行业候选，本地归档还保留下列研究观察。

|观察对象|口径|
|---|---|
|上一交易日强势股|取严格上一开放日的完整涨停名单，区分首板、连板、高度未知以及 10/20/30cm 代码组。断板样本须核验前两个开放日的名单及上一开放日的有效成交。固定组的当日涨跌中位数同向变化至少 1 个百分点，且上涨率同向变化至少 20 个百分点，才记反馈变化。|
|人工核心与同业跟随|核心取前一开放日人工复盘第五步。开盘后改写过的复盘暂停核心观察。核心股当窗区间涨跌绝对值达到 1.5% 后，观察下一完整窗口。排除前窗已同向变化至少 0.5% 的成员，后窗其余同业中至少三只同向变化达到 0.5%，且逐股报价先后可核验，才记录跟随。|
|手写锚点|价格、当日涨跌、相邻窗口涨跌单列。区间涨跌幅绝对值达到 1.5% 可形成独立研究候选。即使行业缺源，锚点行情仍可单独核对。|

代码板型描述股票分组，开板、回封次数等逐笔事件保留为未计算。同业跟随表示观察窗口内的价格先后。缺行情或缺来源的样本保留缺口。

## 本地关键位与已发提醒回看

关键位来自前一交易日晚手写复盘的次日具体条件。个股须绑定已核验锚点，宽基须精确匹配指数。明示的均线点位按整理稿列值固定，早于观察日且有日期证据的前高、前低可作点位依据。保留来源日期、原句、整理稿版本及哈希。指数行情单独归档，来源失败时记录缺口。仅当事前冻结的来源哈希和版本均可核对时才更新相应解析。

同日同半场的相邻采样首次穿越时留档。之后，同一证券、同一点位且同一复盘来源连续至少两批在新的一侧，确认时报价距点位至少 0.2%，才记一次确认。同侧贴线时继续等待，触及点位、折返、缺行情、午休或断档时结束本次等待。当批明细保存在 `key-levels.md` 与 `key-levels.json`，与原报告哈希绑定。

当日 `key-levels-summary.md` 按股票或指数及点位合并确认方向和时刻。个股同时记录首次穿越区间的成交额，取同源、报价时间前进且累计值未倒退的差额，单位为元。用实际两端报价的时间差折算每分钟成交额，除以前五个 SSE 开放日同股、同源、同一对采样时段的每分钟成交额中位数。五日未齐或历史中位数为零时，保留实际成交额和可核验天数，倍数标为未计算。宽基只列点位与确认。

摘要按已接收消息正文中的个股逐条核对下一批表现。下一批继续向提醒方向变化记为延续，反向但未回到提醒区间起点记为部分回吐，回到或越过起点记为完全回吐，报价相同记为持平。比较须满足同源、同半场、计划槽连续且实际窗口可比。等待下一批时记为待下一批，跨午休、半场末批、超过等待窗或缺可核验报价时记为不可比。逐条明细可追溯至实发回执和下一批行情。
