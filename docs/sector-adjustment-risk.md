## 活跃范围

- 申万二级：近5个完整SSE开放日平均成交额前10，并入当日涨幅前5。
- 同花顺概念：近5日平均换手率前8，并入当日涨幅前5；概念日线没有成交额字段，不用成交量假装成交额。
- 每类按代码去重，合计最多28行。排名仅在连续5日可得宇宙中计算，不以较少天数代替5日平均。分类缺失记 `partial`，保存完整缺失代码/名称；取数失败与真实未触发分开。
- 分类为取数时快照，历史补跑不是当年的成分回溯；不以今日行情代替目标日。

## 数据与失败语义

日线使用 `tushare:sw_daily / ths_daily`，分钟使用同一申万指数代码的 `sw_mins(freq=60min)`；概念无核验通过的同口径分钟源时只报日线层。申万分钟权限失败后本次运行熔断重复请求，下一次任务重新探测。不同指数、不同供应商板块和个股K线不互换。

每行保存日线/分钟原始数值、日期、来源、双峰坐标、支撑代理、选择依据及数据缺口。拒绝重复代码/时间、未来行情、错位日期、缺日、非有限数值与非法OHLC。HTML读取时重新计算并核对派生结论。日线可用但分钟缺失仍可展示日线预警，整体为 `partial`，不得标“完整口径未触发”。

概念接口曾混入2026-07-11/12两个周末空值占位行。仅按已验证完整SSE日历排除窗口内休市行，`excluded_closed_dates` 和可见缺口保留记录；开放日坏行、未来行、重复时间均不豁免。活跃榜的个别空指标仅排除该板块并计入覆盖缺口，不拖掉整个分支。

官方接口语义：[申万分钟](https://tushare.pro/document/2?doc_id=469)、[概念日线](https://tushare.pro/document/2?doc_id=260)。首次2026-09-15实测申万分钟返回权限不足；日线分类覆盖不满，按可得宇宙部分覆盖展示。

## 单独补采与HTML消费

```bash
python3 scripts/tools/sector_adjustment_risk.py --date YYYY-MM-DD --input-by codex_automation
```

只写 `data/reports/sector-adjustment-risk/YYYY-MM-DD.json/.html`，不重跑post或推送。刷新时分别比较完整日线和完整分钟的具体代码集合；任一旧有效代码丢失即保留原文件，新尝试及丢失/新增代码写 `.attempt.json`，收据为 `fallback_preserved` 并附尝试文件路径。集合相等允许同日行情修正，新增覆盖也可更新。HTML是②模块预览，不冒充完整八步复盘。

正式 `assemble_report.py` 优先读同日 `post-market.yaml.raw_data.sector_adjustment_risk`；旧信封没有该键时读取上述同日专用JSON。两份来源分别验证日期和证据；时间更晚、有效板块及分钟覆盖集合不退化且实际证据有变化的同日补采可以恢复或纠正信封（包括集合相同但行情已修正），并显示原状态说明。损坏信封可由验证通过的同日专用报告恢复并显示校验失败说明，禁止跨日回退。chunk不得手工注入模块。
