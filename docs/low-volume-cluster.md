# 低位连续堆量与板块背景

来源：已确认的鞠磊2026-11-10课程，`teacher_notes#1178`。首期只增加观察证据，不自动认定资金身份、主线、买点或收益概率。

## 接入与覆盖

复用 `trend-leader daily` 本次已经请求的长窗日线与复权因子。观察对象是主线门内的涨停／双创加速候选及原在池对象，包含未入池和当日退池对象；并非全市场提前发现。名称、代码、当日申万二级、来源及原始行情随既有 `.review.json` 留存，不从当前池重建历史。

新块 `volume_cluster` 只进入现有日报和按日复盘快照，正式HTML⑤通过既有趋势证据模块自动显示，正文先给覆盖与最多3只结构案例，其余结果、口径和来源折叠。代码顺序只是查找顺序，不是质量排名。旧快照显示未计算；缺源显示待核验，不能记作没有形态。休市复盘保持事实日。新块独立重算和降级，不影响原回踩、财务证据的状态。

不新增独立采集、CLI/API、数据库字段、推送或调度；不改变池的准入、退出、排序及已保存信号，不写关注池、认知或交易计划。不恢复已停用的板块核心联动模块。10点环境、个股分钟背离、全市场提前发现与仓位检查属于后续阶段。

扫描对通过主线门的候选和已有在池对象请求最多 400 个自然日的行情。原池检测继续使用原短窗。复权沿用留池对象的既有调用；对未入池、当日退池的对象，只有当次 Tushare 日线达到 120 根才取对应因子。长窗取数失败时，原扫描的短窗能独立重试。

## 工程口径

以下数值全部是首版观察参数，**不是老师原话、胜率或经过回测的最优参数**。

1. 使用最近120根有效日线，严格核对目标日、重复/未来日期、证券身份、正有限OHLCV和一一匹配的复权因子。只接受已核验的 `tushare:daily` / `tushare:adj_factor`，前复权全部OHLC。中间停牌／漏数未逐日核实，因此只说有效K线根数，不声称连续交易日。
2. 在最近45根中，从近到远检查左右各2根确认的反弹峰；峰前20根最低点为前低，同低取最近一根，反弹幅度至少8%。后续须出现低于该前低的新低，才进入本课“再破低”分支。它与 `bottom-rebreak` 要求回调不破低的分支独立。
3. 峰确认后检查5根窗口：至少3根阳线，每根阳线的成交量均至少为前次反弹段均量的1.2倍，5根均量也至少为1.2倍。前次反弹段为前低日至峰日（含首尾）；允许窗口内夹阴线，不把单日巨量冒充连续堆量。
4. 位置使用堆量结束时已可见的60根前复权高低区间。堆量窗口最高价处于区间下方35%以内，且距该区间最高价至少20%；后续涨跌不参与这一步。堆量期间不能跌破再破低点。
5. 每个反弹峰固定首次合格堆量，超过20根有效K线不再当作新事件。多个峰以最近已确认峰优先，不按未来收益或当前强弱选择。结构后续任何一根低点跌破再破低点即失效，反弹回去也不复活同一结构；新峰、新低、新堆量可构成新的观察。
6. 堆量后，收盘低于堆量窗口最高价且后续最近最多3根均量/堆量均量≤0.75，标记缩量回踩；收盘超过前次反弹高点单列。若结构已失效，优先展示失效。数值、阶段和板块背景分别展示。
7. 从前低到观察日跨复权因子变化时，不直接比较原始成交量，保留待核验；这是包含分红在内的保守口径，可能降低覆盖，不能作为形态阴性。
8. 板块背景只认同日完整 `sector_increment` 及当日申万二级映射；复算成交额变化与份额变化。行业不等于概念，成交额不等于净流入，背景缺失不否决已经核验的个股量价事实。

### 部分覆盖时的行业成交额

趋势任务读取同日盘后信封内的 `raw_data.sector_increment`，兼容扁平旧档。日期冲突或嵌套损坏时留缺。行业支持判断仍要求完整来源。

当原行业块为 `partial` 时，新归档额外展示同一行业两日均有行情的固定样本数、前后成交额与增减。逐股成交额须同时与行业及市场合计对账，观察证券须与事实日行业成员记录一致。字段 `coverage.sector_sample_available` 表示映射到共同样本的观察证券数，与完整行业支持覆盖 `sector_verified` 分列。两日一侧缺行情的证券不进入固定样本。沪深数据缺口逐日与既有 `regulatory_suspend` 归档核对，保留已核全天停牌代码及来源记录编号；没有同日成功来源或只有盘中临停的代码留为原因待核。原块状态保留，历史报告按其原始证据和版本重算。
