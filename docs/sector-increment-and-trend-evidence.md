- `main.py post --date YYYY-MM-DD` 随原20:00流程采集 `raw_data.sector_increment`，沿用盘后信封与 `daily_market` 双写，Markdown展示全行业表。正式每日复盘HTML组装器只读同日信封并注入②板块，缺口进入运营区。
- `main.py trend-leader daily` 在原状态转换后附加启动/回踩证据和股东户数/业绩卡。报告、推送开关沿用原入口；`--dry-run`内存副本，`--no-push`落本地不推送。
- 新证据保存在既有 `last_signal_json`，`trend-leader pool --json`可读取。代码升级后从下一次正常运行开始生成，旧报告不回写。

## 板块增量归因

沪深A股含ST、剔B股、不含北交所；Tushare `daily.amount`千元换算亿元；采集时申万二级快照同时归类两日，非历史成分回放。展示行业成交额、增额、全市场份额变化(pp)、市场净增额贡献(%)，保留负贡献和超过100%的贡献。全市场净增额≤0或不足昨日市场额0.5%时贡献率为null/未计算；0.5%是稳定分母的工程门槛。成交额不等于净资金流入。

严格上一开放日来自只读SSE完整日历，上海16:00后才取当日行情。每日行情≥4000只、上市宇宙覆盖≥98%、两日共同代码/并集≥98%、行业映射覆盖≥99%。重复、日期错位、金额缺失/负值/非有限数失败封闭。部分宇宙无行情（可能停牌，尚未验证）、未分类保持partial，不补0；非共同代码单列。硬失败source_failed；休市或未收盘skipped。消费端复核总额、行业增额、份额与贡献算术。

## 放量后的回踩

复用 main 既有扫描日线窗口（默认90自然日），不重复获取行情；在原池转换完成后仅为在池观察对象追加同区间复权因子调用。不携带尚未发布的均线扩窗改动。新观察单独对全部OHLC前复权，校验重复、缺因子、错序、目标日缺失和非法OHLCV；至少30根有效K线，以完整验证近20根启动及MA10结构，26～29根仍标数据不足。工程代理：最近20根中，阳线收盘突破前5根最高价且vol≥前5根均量1.5倍，取最近一次启动。

启动当天不算回踩。启动后任何一根触发原趋势破坏规则或最低价低于启动K线最低价，旧启动失效，不被后来反弹复活。当前缩量阴线和贴MA5复用原检测器；同日完整板块增量块中行业增额、份额变化均>0才算板块支持。partial/source_failed块不作完整支持证据，形态成立时明确“板块支持待核验”；没有启动/支持转弱/缺数据分别显示。这些参数未经收益验证，不是老师原话或交易指令。

## 股东户数与已披露业绩

新增provider capability `get_stock_holder_numbers(stock_code,start_date,end_date)`：`stk_holdernumber`公告窗口、保留截止日与公告日；单股返回触及3000行上限则来源失败。现有 `get_income_history`增补 `ann_date/f_ann_date/revenue` 字段，保留旧字段。

每次从观察日有效在池名单按代码取前12只证据卡，窗口800自然日，每只两次源调用；列出全部未采集代码，非质量排序。户数取不同截止日的最近两期，按当时已公告版本取最新，同期同公告冲突拒绝。利润表接受普通合并 `report_type=1` 与调整合并 `4`（兼容数值类型），可见日取 `max(ann_date,f_ann_date)`；先剔除未来公告，再复用现有财务快照的修订标记、报表类型、可见日优先级选择版本。同一优先级金额仍冲突则拒绝，不按来源顺序随意选值。比较上年同报告期；同比=差额/上年绝对值，分母0不算。

不足两期、缺公告日、缺同比、未来版本不可见及来源失败均显式记录。户数变化不证明机构持仓、被套或将自救；已披露业绩不保证未来业绩。
