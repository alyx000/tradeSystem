# 板块核心联动观察

出处：鞠磊 `teacher_notes#1089`，归入2026-10-31技术课，保留2026-10-30小组讨论原始日期；对应31:09—32:42。模块只读派生，不新增核心身份、业务表、调度、采集、推送或计划层写入。

## 来源与时点

- 严格SSE日历连续覆盖观察日及之前5个开放日；目标日必须开放。5日是工程有效期，不是课程参数。
- 身份取观察日前5个开放日内最新一份 `daily_reviews.step5_leaders`。只读已经保存的复盘，不读取 `daily-leaders` 提案、备选或自动趋势池。最新记录损坏或空名单不回退旧名单；读侧复核最多15只、代码/名称唯一、同板块同角色唯一，旧数据不合规整体拒绝。同日确认的最票留待之后观察，避免用今日赢家反推昨日核心。
- 展示身份归档日和相隔开放日数。复盘记录可被事后修改，当前数据模型无法证明当时确认时间；本模块不宣称提供无前视偏差的历史回测。
- 沿用该份复盘的股票、板块和四种角色；代码缺失、未知角色、未分类单列缺口。绝不因成交额排名授予中军身份。
- 当日容量读取 `daily_volume_concentration.source_json.capacity_trend`；只使用有效逐股证据，`fallback_preserved` 不参与联动判断。行业与身份归档不一致时不合并。前一开放日同股同行业容量用于弱项新增/持续/解除比较。
- 断板只在前日连板次数已核验≥2、当日完整涨停名单成功、当日确实有交易且未涨停时成立；当日交易证据取同日 `strong_stock_feedback`，来源日必须严格等于前一开放日。不把停牌、缺行情或默认板数当成断板。
- 前排收盘反馈只复用同日 `strong_stock_feedback` 可计算行情。未在昨日涨停样本中的核心保留未覆盖，不额外请求行情。

## 展示口径

| 项目 | 事实与观察规则 |
|---|---|
| 趋势中军弱项 | 前复权收盘位于MA20下方且末端连跌≥2根有效K线；有效K线不等同连续市场开放日 |
| 连板核心弱项 | 已核验前日连板→当日有交易且未涨停 |
| 前排活跃／弹性前排弱项 | 次日收盘涨跌幅<0；收阴与收跌分开，不混用 |
| 多类核心同日弱项 | 至少两种不同角色出现弱项；这是规则化[判断]，不是板块退潮、因果带动或相关系数 |
| 局部弱项 | 四种角色均有身份，所有已列核心均核验，且仅一种角色出现弱项；否则标已见弱项、其余待核验 |
| 新增涨停样本 | 当日与严格前日完整非ST涨停名单作差，按当日来源行业与归档板块名称精确匹配；概念不自动映射、未分类不聚合，0与缺源分开；新增名单中有行业未知者时仅显示已匹配数并单列未知覆盖，不冒充本板块完整零值；不授予接力身份 |

同日多角色弱项不声称各角色均较昨日恶化；只有容量的逐股前日变化以及核验断板事件具有明确跨日语义。其他变化标未计算。
