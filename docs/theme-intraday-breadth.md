# 前夜题材的盘中扩散

盘后从已归档的全市场十分钟报价，逐批观察前夜题材有多少股票上涨、上涨幅度是否集中、相邻两个时点发生多少成交。开盘前已有的完整概念名单与手写点名的小组在报告中分别展示。

| 观察对象 | 名单依据 | 结果含义 |
|---|---|---|
| 前夜重点概念 | 严格上一 SSE 开放日手写原文或整理稿，版本录入时间早于开盘。同花顺概念代码、成员抓取时间及完整分页均在上一开放日核验。 | 给出名单总数、本批实际报价数、上涨只数、占比及中位涨幅。 |
| 点名小组 | 同日核心股归档中与上述手稿哈希一致的冻结名单。逐对记录核心、对照股票、前夜明确点名以及同题材的独立依据。 | 仅代表这些点名股票。报告逐只给出相对昨收涨跌幅，可看核心与对照的同批差异。 |

同日盘后才知道的成分不进入重放。两个组的共同成员列在 `overlap`，总人数按证券代码去重。若无事前选题、完整概念名单或点名证据，对应缺口随报告保存。

每份十分钟行情检查批次回执、报告哈希、原始报价哈希、股票范围，以及事实日与交易时段。每股都须有本批原始报价中的现价和参考昨收，报价到实际采样时点相差至多 90 秒。上涨占比以有有效报价的成员为分母。全天停牌单列，停牌资料有成交冲突时记为待核，其余缺报价成员单列。读数发生在实际采样时刻，采样间隔内的先后未知。

成交额单位是元。两批行情须属同一半场、相邻十分钟槽、同一来源，个股报价时间前进且累计成交额单调。分别记录有效个股、这些股票的成交额差分合计和全组成交额；只有全体应有成交额的成员齐全时才给出全组合计。午后首批只建当半场基准。回放不访问行情接口。

从项目根目录运行。默认输出摘要，`--json` 打印逐股明细，`--save` 原子保存本地报告，盘中或休市日跳过。已有报告出现成员、样本时点、逐股价格或成交额覆盖退化时，保留原报告并记录本次尝试。输出位置为 `data/reports/theme-intraday-breadth/YYYY-MM-DD.json`。

```bash
python3 scripts/tools/theme_intraday_breadth.py --date 2026-11-27 --input-by USER --save
```
