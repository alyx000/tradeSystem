## 行业缺口与保守下限（2026-11-16，当前v3）

`industry-bounds-sector-priority-v3`修正v2两处过严门槛，以下规则优先于旧说明：

1. 行业覆盖先核对全市场缺行情代码名单与分母，复用通过验证的同日`market_strength`行情/申万来源；再从同日已归档、同申万来源的`sector_increment.components`解析缺行情对象归属。辅助来源必须同日、唯一且与已知行业一致；来源错位、冲突或未知保持未解析，不拿当前成分回填。每个行业分别列出本行业已定位缺行情、已定位其他行业、归属未知对象。其他行业缺口不降低本行业覆盖；未分类的已有行情对象也纳入潜在缺口。只读原档，不改事实层或新增请求。
2. 本行业已定位缺行情，加上所有归属未知对象全部划入本行业，计算中位涨幅及上涨占比的最不利补全范围。未知涨跌方向不补0、不设人为收益上下限；中位无有限界时标未知。`bounded`保留partial，但允许用范围证明优势；没有潜在缺口才是行业complete，不能把全市场partial机械传给每个行业。
3. 真正执行板块优先：同日同口径的两个不同板块，若A的中位涨幅下界严格高于B上界，且A的上涨占比下界也严格高于B上界，则程序直接判A胜（反向同理）。这种对局不调用LLM、不允许个股涨幅推翻，理由标`[程序·板块优先]`。这是明确的工程比较规则，不是经过回测的胜率，也不是任意加设60/40权重。均值与强弱尾部仍展示，作为核心指标未形成稳健共识时的补充，不否定已成立的程序条件。范围相交、同板块、核心方向冲突或无法核验时，才由LLM结合个股与路径裁决。原强池、八维加权榜、预算/失败熔断、胜场及破平不变；`--no-llm`仍不跑整套PK。
4. 一价占比分母必须由各段末日的有效历史涨停来源核验连续板数（反包段首板另列，不拼接连续高度）。已知一价数I、已知非一价数H、核验总板数N，则占比范围为`[I/N, (N-H)/N]`。下界严格大于50%即可确认一价居多，partial仍参与比较；例如3次一价、总4板、1日未知，下限75%。分母未核验、上下界跨过50%不能断言；只有H=N才称一路非一价换手代理。逐日缺口继续保留，不把未知日伪造成一价或非一价。
