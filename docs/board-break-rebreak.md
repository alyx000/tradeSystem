# 断板反包盘后：反包后再断板分支

钉钉摘要显示已核验候选数，从加权榜和有效 PK 榜各摘录前 3 只，同一股票合并展示。数据缺口及 PK 未完赛会提示，完整榜单、评价口径与逐场理由见本地 Markdown。

## PK统一评价口径（2026-11-16）

用户明确要求近期涨幅按辨识度统一看待、反包后再断板不天然判弱。PK提示词版本为`recognition-neutral-branch-v1`：

- `gain10`只作正向辨识度证据：数据有效时，更高涨幅表示该维度辨识度更高；不奖励涨得少，不仅因涨得多而判透支/过热。辨识度高不自动等于整场获胜。
- `branch`为中性形态。跨分支同时读取当前连续板数、前段高度和近期涨幅；不把1板小于2板或“再次断板”标签当作天然弱势，也不拼接连板数。
- 当日涨跌幅、主线及公告/业绩等独立事实可以影响胜负；不能把日线表现冒充已核验分时承接。区间位置只作背景，不暗中替代低涨幅奖励；风险须有独立事件证据。MACD比较零轴状态，不用跨股DIF绝对大小直接判强弱。
- 辨识度与当日表现冲突时，理由须交代双方优势及决定胜负的独立证据。理由保留上限从60字扩至120字，避免取舍解释被截断。
- 新结果/报告记录口径版本和摘要；旧结果无版本时不冒称按新口径生成。加权评分、候选筛选、模型配置、循环赛与破平方式均不变。
- 这是统一模型判断的提示词约束，不是机械胜负公式或通用语义违规检测器；测试覆盖实际调用的口径与事实卡、理由保留及版本展示，真实重跑另逐场核对理由，不宣称单元测试已证明模型永远遵守语义。

## 筛选口径

原分支不变：T-1连续涨停≥2，T未涨停、未跌停、涨幅≤6%，10cm主板非ST。

新分支按本地已核验SSE日历的四个相邻开放日逐日确认：

| 日期 | 必须满足 |
|---|---|
| T-3 | 涨停名单中存在，已核验连续板数≥2，非ST |
| T-2 | 有当日日线，未涨停、未跌停，涨幅≤6% |
| T-1 | 涨停名单中存在，已核验连续板数=1 |
| T | 有当日日线，未涨停、未跌停，涨幅≤6% |

四日均须有唯一、有效日线，收盘价为正且涨幅有限；来源提供成交量/额时必须有效且为正。仅10cm主板、按T-1身份剔ST。日历逐自然日回溯，休市日也须有明确记录；不跳过停牌、缺失开放日，不用自然日减一或最近行情替代。最多回溯45自然日查四个开放日，新旧分支上一交易日必须一致。

“反包首板”在本分支指断板后的下一开放日重新收盘涨停；不额外要求反包收盘价超过前段最高价，不把“多日多板”当作连续板数。跨多日整理、首次断板超过6%或跌停的情形不在此分支。

## 数据与展示

- 复用本次T-1涨停、T涨停/跌停结果；仅新分支存在待核首板时请求T-3涨停、T-2涨停/跌停名单，符合前段形态后读取该票日线。无额外模型或独立调度。
- 新分支`limit_times`始终为昨日真实值1；`branch=rebreak`，`pattern_evidence`单列四日日期链、前段高度、首次断板涨幅、反包收盘与涨停来源。原分支标为`consecutive_break`。
- 原有八维评分权重不变。分支及形态证据随事实卡进入原PK，不将前段3板与昨日1板相加。报告增加入选分支列、逐股日期链；复盘HTML兼容旧10列表格与新11列表格，只允许带反包分支身份的1板候选。
- 新分支状态独立为`complete/partial/source_failed`，日期、来源、筛除计数和缺口列在报告中；新分支不完整时整份结果为`partial`，保留原分支候选，HTML保留可核验排名并登记ops。没有已核验候选时只报覆盖缺口，不报全量零候选。原三核心源/原分支全部行情失败仍沿原失败规则处理。
- 原分支“连板数<2”是该分支入口筛除数，不等于双分支最终剔除数。
- 不写业务库、关注池、计划，不改尾盘/开盘复核规则、不新增推送或调度。历史诊断只读归档，不覆盖历史正式清单、不补发。
