使用指引

1. 本模板可以独立使用，也可以和另外两套模板组合完整复盘流程： ①趋势分歧买点模板（趋势板块） ②情绪周期龙头接力模板（连板投机） ③板块推演术模板（板块层面大框架）

2. 板块推演术是上层框架，先完成板块推演，再落到个股，选择用趋势分歧，还是龙头接力模式。

3. 板块周期只需要粗分，不要过度抠细节，重点看「加强 / 减弱」的连接点。
