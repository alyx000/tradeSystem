# 每日复盘图形层

2026-10-29 用户确认采用「顶部摘要图 → 章节关键图表 → 折叠证据」布局。

## 生成与边界

- `assemble_report.py` 的 `attach_visuals` 自动内嵌 `review_visuals.css` 与 `review_visuals.js`。本地单文件、无需网络或额外图表库；无浏览器存储、业务写入、取数或推送。
- 图表只投影报告已有的已核验证据。原始表格与日期属性保留，由原校验器继续逐源验证；JS 关闭时原文仍可完整阅读。新增图形不产生额外判断或综合评分。
- 缺值、错日、来源失败不补零；不能解析的面板显示缺口并登记到图形覆盖卡，不能宣称无信号。休市旧事实只在来源状态卡显示原事实日，不冒充当日新图。
- 每图带「查看依据」，自动展开相应证据。全局搜索、证据开关、原15章导航保持有效。矩阵窄屏局部横向滚动，文字/箭头冗余标记颜色语义。
- 更新已交付报告须有用户授权，先保留副本。模板变更不自动改写历史报告。

## 身份图形来源

主会话保存 provider 原始回执到 scratchpad 的 `visual_identity_sources_<报告日>.json`，由程序序列化已有来源，不手编计数。键为双日 `YYYYMMDD_U`、`YYYYMMDD_st`、当日 `YYYYMMDD_daily` 和 `YYYYMMDD_identity`。前三类保存 `api/params/status/rows/pages`；页偏移每2000递增、末页为空、行日期与请求一致、代码唯一。日线不少于4000行；ST名单非空。

五日热力图须补齐正式新高manifest交易日脊柱最后五日各自的U/ST原始回执；优先复用同事实日已有完整归档并记录文件路径/SHA/键，来源缺失仍显示缺口。`review_sector_visuals.py`只做内存重算、不取数或写库；当日日线与成员映射有缺口、ST身份不一致均保留partial。行业`in_date/out_date`是成员关系日期，不能当上市/退市身份日期。

### 热门题材视角

同一热力图提供“申万行业／热门题材”切换，保持16个面板。题材按每日原始 `limit_cpt_list` 榜单（[字段说明](https://tushare.pro/document/2?doc_id=357)）显示 `up_nums` 涨停家数、`cons_nums` 连板家数和原榜排名；默认今日原榜前10，可展开今日原榜全部项。原榜含泛概念及少量行业，不声称是纯概念全集，也不把 `cons_nums` 当概念成员数或套用≤300过滤。

主会话只读导出 `raw_interface_payloads` 对应日期的原始回执到身份来源文件键 `YYYYMMDD_theme_ranking`：`id/interface_name/provider/biz_date/target_date/status/row_count/payload_json/payload_hash`（可保留source_meta_json/inserted_at供追溯）。原始payload_json字符串必须原样保留，使SHA256与归档payload_hash一致；内部事实日、请求、provider、行日期/代码、计数、唯一排名1…N、行数均严格校验。

`review_theme_visuals.py`只投影已有归档、不取数/写库。各日未收录题材不生成counts键，UI显示“未录”，不补0、不把未收录断言为当日没有涨停；整日失败为null并显示“缺”。榜单范围不是全题材覆盖，因此状态partial。没有完整当日逐股成分归档时，可以补充有同日证据的部分名单与原因涉及股票，但必须分层标识、保留原原因与匹配规则；不把过期成员或少量候选关联拼成完整名单。不声称已剔ST，与行业图口径分开；多题材可重叠，不能跨行加总为市场家数。双视角都失败/缺失时外层状态保留source_failed/missing-data，不能误报partial。

`identity` 来自报告日抓取的 `index_member_all`，保存 `api/status/as_of/fetched_at/rows`；成员行保留 `ts_code/name/is_new/l2_code/l2_name`，`is_new=Y`。同一股票重复同分类折叠，缺映射或冲突只计入一次未分类。明确带“退市”名称的旧 `Txxxxx.SH` 身份不属当前A股代码宇宙，其余非法身份拒用。两日均按同一报告日申万二级快照归类，明确非历史成分回放；同花顺多标签概念不混入互斥行业统计。

正式CLI从 `--new-high-manifest`（默认 scratchpad 的 `new_high_<报告日>.json`）及上述回执生成内嵌 `review-identity-data`。直接调用 `validate_report/write_report` 时需传入相同 `new_high_manifest`、`visual_identity_sources`，逐项与源重算结果相等才通过；有效图形不能以手填JSON替代来源。`render_report` 单独调用是结构预览，未提供身份原始回执时由正式CLI在写入前补上已核验的新高输入。缺源显示 missing-data，失败保留 source_failed 和原因，不复用其他日期。

稳定表头和列顺序是当前展示契约；作者如调整表格，须同步适配器与测试，不从任意正文猜数。日期由报告自身的 `data-report-date` 提供，结构化来源必须同日；若不满足输入契约，保留原证据并显示图形缺口。

板块涨跌段落由主会话根据当日行业源核验后标记，可放在s2现有证据中；不能给前日、近5日、预测或条件句附当日事实标签。没有上述显式契约就不绘涨跌部分，仅保留有据的浓度图并标partial。容量/日线表格价格已圆整，显示值相等用“≈待核原值”，不能据此制造精确贴线结论。

## imagegen 摘要图

配图是可选的一层。用户要求或已授权生成时用内置 imagegen，校对关键字与数值后保存到 `data/reports/review-images/<报告日>/`：

- `01-复盘摘要.png`：默认展示。
- `02-结构分化.png`、`03-验证条件.png`：折叠展示。
- 完整提示词留在同目录，事实/判断标签保留，不生成虚构K线或目标价。

组装器只读取这些精确路径并内嵌PNG；没有图片时不阻塞图表生成、不复用前日图片，也不自动调用收费生图。历史已链接文件可保留，通用文件名供组装器使用。
