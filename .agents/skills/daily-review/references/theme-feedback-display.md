# 题材反馈：简洁对比格式

2026-11-16：正式`theme_feedback.render_html`已实现下述简表和折叠，主会话不再另写重复阅读入口。行情覆盖完整才画上涨占比条；只有所有展示行的上涨/涨停覆盖完整且逐股核验子集关系时，末列使用“其中再涨停”，否则全表使用“再次涨停”并保留独立覆盖。完整0样本显示“无样本”。

2026-11-10 用户确认：以后复盘的题材反馈统一采用当日最终简版，不再默认展示逐股方格、价格路径或多指标统计长句。本要求优先于旧的“正文最多3个题材、逐题材长段摘要”。

## 默认展示

- ②板块内用一张紧凑对比表/条形图覆盖本次有来源的全部题材，通常为严格上一开放日榜单前10；保留来源榜单顺序，不自行制造强弱排名。
- 标题为“昨日涨停股今日表现”，注明来源日→反馈日及单位“只”。样本是昨日固定涨停名单，不是整个题材，也不能换成今日涨停名单。
- 四列固定为：**题材｜昨天涨停｜今天上涨｜其中再涨停**。完整数据时直接显示数量，不在正文堆叠`16/16`、中位数、10/20/30cm等缩写。
- “今天上涨”附一条细横条，长度为上涨数÷昨日固定样本数，范围固定0～100%；数字仍须明确显示，不能只靠颜色理解。
- 简短注明“条长＝上涨占比；再涨停含在上涨内；题材不相加”。跨题材存在重复股票，不求总和。
- 分板型、开收盘中位数、收阴、量能、逐股名单、来源与计算口径保留在可展开证据中。默认不再添加逐股点击方格、价格路径、交互教学或长篇白话说明，用户另有要求时再展开。

## 缺口不得被简化掉

- 昨日样本未核验：显示“待核”，不能写0；已核验样本确为0时，昨日显示0，今日反馈显示“无样本”。
- 行情或涨停覆盖不全：相应格明确“待核”或“已核验N只，覆盖X/Y”；不把部分已知数量当完整样本结果，不画看似完整的占比条。不同指标的已核验分母仍在证据中保留。
- 只有上涨和再次涨停均完整且来自同一固定名单时，才用“其中再涨停”的子集说明；否则列名用“再次涨停”，显示独立覆盖说明，不暗示已验证子集关系。
- 缺源、未计算与正常0分开；休市时仍按完整日历证明的事实日显示明确日期。量能缺口放折叠证据及既有缺口摘要，不能据缺源判断缩量。

## 生成与验收

- 数据沿用正式`theme_feedback`只读重算结果及来源签名；逐题材核对固定样本数、收涨数、再次涨停数和条宽，不新增取数、入库、推送或交易结论。
- 第2路提供全量题材结果与覆盖；主会话按本格式组装，检查电脑/手机一屏内易比较，详情默认折叠。旧模板长句不能作为最终默认展示。
- 当模板仍产出旧式摘要时，主会话须将源可核验的简洁总览作为阅读入口，并把原统计收进证据；不能仅因旧模板通过结构检查就忽略本偏好。
