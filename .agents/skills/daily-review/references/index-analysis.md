# 各大指数：趋势、动能、量价与跨周期检查

用于每日复盘 HTML ①大势，第1路必须读取。扩展既有日线 MA5/MA10 检查，由 Agent 只读取证、计算并写入报告素材；**目前是生成流程要求，不是组装器自动计算或新增硬门**。不新增定时任务、业务写入、正式评分或交易建议，不重写历史报告。

## 来源与适用范围

方法来自用户于2026-09-13提供并确认采用的课程转录中微盘股分析段：60分钟转弱、日线MACD红柱缩短、上涨缩量、日线MA5走平并观察MA5/MA10下穿。该日期是提供材料日期，**不是已核实的授课日期**；作者、微盘股代码及图形未由这份文字确认。

以下参数、窗口与解除条件是系统为可核验复盘制定的操作口径，不能归为老师原话。“双头”“必出中阴线”“某日向下变盘”不转成确定规则；只迁移观察方法，不推广那次市场结论。

至少覆盖上证、深成、创业板、科创50、中证2000（932000.CSI）、平均股价（880003）；报告另列沪深300、上证50、中证500、中证1000时，同样逐项检查。指数身份包含代码、来源与周期，同花顺/万得微盘股、中证2000与国证2000不得混称。

## 取证与计算

1. 事实日T为报告窗口最近已收盘开放日。沿用既有只读镜像与行情入口，保留来源、事实日、抓取时间、字段单位、实际查询与输入序列；日线逐日与本地完整开放日历核对，不使用T之后数据。价格须唯一、有限且为正；缺日、重复、陈旧或身份不明时，受影响指标标“未计算”。MA有效而MACD长窗不足时保留MA；分钟缺失不否定有效日线。
2. MA5/MA10取最近11个完整开放日收盘；今日均线用末5/10根，前日用截至上一日的5/10根。MA5由不低于MA10转为严格低于才称“本日死叉”；此前已低于称“死叉后仍在线下”，相等为“贴线”。展示今日/前日MA5、MA10、点数差及其日变化、归一化差距 `100×(MA5/MA10−1)`。MA5今日减前日为正/零/负分别称向上/走平/向下，比较未舍入值，不凭显示值相等或自设容差称走平。当前MA5>MA10时，把今日收盘追加一次并滚出旧值重算末5/10根；试算MA5<MA10才标 `[判断] 次日平收情景死叉预警`。仍在线上且正差收窄但试算未下穿，写“收敛中，平收情景未死叉”；不能仅外推斜率，未触发不代表未来不会死叉。上述日线定义优先于旧流程仅描述均线位置的简略要求。
3. 日线MACD固定12/26/9，柱值为 `2×(DIF−DEA)`，EMA以样本首根收盘初始化，与 `scripts/utils/pattern.py` 一致。固定取最近**124个完整开放日**，在同一EMA序列保留最后5日DIF、DEA、柱值（首个展示日已有120根预热）；不足时MACD未计算，不能用11根MA输入硬算，不能对最后5日分别初始化。保留窗口起止和参数；跨日变化在本次共同窗口内比较，避免混用昨日报告不同预热窗口的值。
4. 正柱连续缩短须相邻柱均严格为正且后柱小于前柱，只报最后5日内的连续缩短步数（最多4步），不能称全历史持续天数。负柱绝对值缩短是负动能差收窄，不得同样解释为走弱。DIF由不低于DEA转为严格低于DEA才称本日死叉，此前已低于称死叉后仍在线下，相等为贴线。两线零轴位置另列，不把柱值正负当成两线同时在零轴上下。
5. 量价固定展示 `C[T]/C[T−5]−1` 的5日涨跌幅、最近5日量能均值/此前5日均值、T日量能/此前5日均值。优先同指数同源 `amount`，无成交额时允许整窗统一用 `vol` 并明确“成交量”；不跨日混字段，不用全市场成交额填某指数。完整10日量能须有限且大于零、单位一致，否则量价未计算，不能将零当缩量。5日涨幅>0且两组5日均值比<1才写“近5日价升、量能均值低于前5日”，不等于逐日越涨越缩量。
6. 全市场成交额另列背景，沿用已有滚动峰值/均值和覆盖口径，不把课程当时的绝对成交额阈值固定用于以后所有交易日；成交额变化本身不称场外资金净流入。

## 跨周期与情绪验证

分钟事实沿用当前发布版本的正式取证路径：若已有 `build_index_intraday_manifest.py`，只消费其官方 `index_intraday_<REPORT_DATE>.json`，保留六指数×15/30/60分钟18行及来源校验；若发布版本尚无该组件，沿用现有流程的pytdx只读30/60分钟取证，保留代码、周期、参数、输入、末根时间与失败收据，不虚构sidecar或宣称自动校验。60分钟为主要短周期对照；日线MA/MACD统一按上方完整日线窗口计算，不用分钟数据代替。

- 只有**同一指数、同一事实日、完整收盘周期**才能对照日线与60分钟。当前分钟国证2000（399303）代理与日线中证2000（932000.CSI）只能并列观察，禁止合并成同指数共振或传导；原分钟代理行保留，不用日线补位。
- 同时转弱可写 `[判断] 日线与60分钟转弱条件同时出现`；仅有当日快照不能说“60分钟率先转弱并传导至日线”，先后顺序须同指数历史证据。均线与MACD都源于价格，不作为相互独立的多票验证，不统计为成功概率。
- 红柱缩短不自动命名顶背离；现有机械底背离不能当顶背离或双头证据。拐点、比较窗口与确认时点未另定义并验证前，不自动输出“双头死叉/顶背离已成立”。
- 同时检查反向证据：60分钟恢复而日线仍弱、日线保持均线位置但动能收窄、量能恢复而广度未修复，均保留分歧，不能只搜集转弱证据。
- 微盘/小盘代理只作风格与风险偏好观察；全市场情绪须结合当日非ST涨跌停、连板晋级、核心股反馈和上涨率。其他指数按自身身份解释，不将所有指数都叫情绪锚。

## HTML 展示

沿用①大势“一句裁决、最多三条增量证据、一条证伪或缺口”的正文预算。将日线MA摘要扩为综合指数摘要，不新增默认展开大表。已有分钟模块保留，不手写替代自动模块或重复复制明细；尚无自动模块的发布版本仍用原分钟证据表。

默认折叠的“指数趋势、动能与量价证据”与原日线MA明细放同一证据区域，可拆窄表避免十几列溢出。**保留原MA数值和平收情景表**，新增表按下列列组展示：

| 列组 | 必须展示 |
|---|---|
| 身份与趋势 | 名称/代码、事实日、收盘相对MA5/10、MA5方向、实际交叉和平收情景（数值见原MA表） |
| 日线动能 | 最近5日柱值、窗口内正柱连续缩短步数、当前DIF/DEA、零轴和交叉状态 |
| 量价 | 5日涨跌幅、近5日/前5日量能均值比、T日/此前5日量能比、量或额及单位 |
| 60分钟对照 | 同指数有效事实摘要，或“代理不可合并/未计算”，引用原分钟折叠表 |
| 解释与缺口 | `[判断]` 证据组合、解除/进一步确认条件、缺失字段与来源 |

正文只点名状态变化、明显分歧与不可判指数。计算数值和已发生交叉标 `[事实]`；动能衰减/修复观察及未来条件标 `[判断]`。缺源保留 `partial/source_failed/missing-data`，逐项未计算并进入 `ops`，没有预警与无法计算不混同。

以下仅示范组织句子，**必须按当日事实填充，不得直接复制为真实行情**：

> [事实] 某指数仍收于日线MA5上方，最近5日内正柱连续缩短2步，60分钟已出现MACD死叉。[判断] 短周期转弱、日线动能收窄，但价格趋势尚未同步跌破；观察实际日线MA5/MA10是否下穿。若60分钟重新金叉且日线正柱停止收缩，应按当日事实解除或降级对应提示。

解除条件须对应原观察：正柱停止缩短仅解除“持续缩短”，不自动宣布趋势修复；MACD重新金叉不自动解除MA死叉；数据丢失不算解除。禁止必跌、确定变盘日、中阴线概率、价格目标或交易动作。

## 生成与验收

1. 第1路在 `market_YYYY-MM-DD.md` 保留 `index_analysis` 素材和原 `daily_ma_cross_check` 输入；每个指数每项都有事实值或明确缺口。用只读脚本计算并保留实际查询、窗口与输入，不由模型心算或编造。
2. 主会话抽查至少一个可判指数的MA、MACD最后5日与量价比，逐一核对跨周期代码和日期；无可判指数时核对缺口收据，不将复算标通过。11根足够而124根不足时须允许MA有效、MACD未计算。
3. 内容验收考虑正柱缩短未死叉、已死叉、负柱缩短、贴线、量能缺失、分钟全缺、代理错配及反向修复；不要求每天都有所有形态，但实际出现的情况必须按规则解释。
4. 继续经过正式组装器既有校验，实际生成报告时在浏览器检查正文预算、折叠表可读性和缺口可见。本规范尚无自动硬门，组装成功不能替代复算与内容验收。
