# 市场连续跌停股票：每日复盘固定项

用户于2026-11-02明确要求以后每份复盘都包含此项。由多Agent第3路采集核验，主会话放入③情绪；不能用当日跌停家数、部分核心负反馈或断板次日统计替代全市场连续跌停名单。

## 事实口径

- 默认指截至事实日仍连续至少2个市场开放日**收盘封于跌停价**；盘中触及跌停后打开不算收盘跌停，普通连续下跌不算。逐股核验真实跌停名单或当日有效的未复权收盘/跌停价，不以固定跌幅阈值（如−9.9%）猜测。
- 覆盖沪深北A股，非ST主表与ST风险警示股附表分开，不混加；排除B股及已退市证券。按每日有效身份/涨跌幅限制核验，上市无涨跌幅限制日不能套常规跌停价。源若只覆盖非ST或缺北交所，明示缺失范围，不能冠以全市场完整。
- 使用完整交易日历逐开放日向前核验，周末/假日不计天数。停牌/无交易不跨过拼接“连续市场开放日跌停”；无法判明停牌、行情或跌停状态时列待核验。报告日休市沿用经日历确认的最近事实日，单列报告日与事实日，失败不回退旧日。
- 精确连续天数和起始日须一直回溯到前一个已核验非跌停开放日或可证明的上市边界。窗口左侧或途中缺源时，只能写“至少N日（已核验区间…，起始日待核）”，不能把窗口起点当成真实起始日；未知不能当作中断、单日或零只。

## 展示与来源

③默认显示总览、事实日及覆盖状态；完整名单放同节可展开证据，股票默认名称＋代码。按连续天数降序、同天数按代码查找，不赋予交易优先级，不截成Top3或只选核心票。

逐股保留：名称/代码、ST与板型身份、连续天数（精确或下界）、起始日（或待核）、已核验日期区间、当日涨跌幅、逐日跌停证据和来源。行业可附加但不得以当前成分冒充历史归属。缺行情、缺身份和不可判连续性的股票单列，不从分母静默删除。

第3路在`emotion_<报告日>.md`提供`consecutive_limit_down`素材：来源及日期、完整性/分页收据、逐股逐日核验、名单、待核验对象、统计口径。复用只读盘后归档/原始事实；需补取时保存原始回执到本次scratchpad，不改历史归档或业务库。主会话逐项复算后写入s3 chunk。

- 完整覆盖且确认无连续跌停时，明确写“无连续跌停股票（完整核验）”。
- 部分覆盖保留已核验名单并标`partial`；核心来源失败标`source_failed`，未计算标`not_computed`。无有效样本时显示“未核验/未计算”，不得写成0只。缺口同步进入`ops`。
- 交付前检查该模块实际存在、来源日期一致、连续天数/起始日可追溯，并与当日跌停名单对账；名称、代码、缺口在桌面及手机可读。预算不足先精简重复说明，不省略本项或截断名单。
